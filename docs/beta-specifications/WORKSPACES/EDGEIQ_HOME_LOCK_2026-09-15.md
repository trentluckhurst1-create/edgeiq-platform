## Global shell
Home uses the exact same approved EDGEiQ light-theme shell as every other workspace: WHITE sidebar, canonical EDGEiQ blue, navy text, thin cool-grey borders, restrained shadows, compact professional typography and the SAME canonical EDGEiQ brand asset used everywhere else.

## Canonical EDGEiQ brand — IP HARD LOCK
The EDGEiQ logo/wordmark is product IP and must be pixel-identical on every workspace. There must be ONE canonical source asset/component. Home, Meetings, Race, Form, Performance, EPI Ratings, Speed Map, Market, Results, Track, Weather, Overview, Insights and Settings must never redraw, restyle, regenerate, retype, approximate or independently construct the logo. The same asset must render at the same proportions, colours, lettering and tagline treatment throughout the application. Logo drift is a release-blocking defect.

## Home purpose
Home is the professional racing-intelligence landing dashboard. It gives immediate orientation and fast routes into the day's racing without duplicating specialist workspaces.

## Approved Home composition
- Welcome/brand statement using EDGEiQ Professional Racing Intelligence language.
- Restrained racing hero/banner treatment consistent with the approved mockup; no bookmaker/casino styling.
- Three-day summary cards: Today, Tomorrow, Day +2, showing canonical meeting/race totals only.
- Quick navigation to key workspaces such as Form, EPI Ratings, Market, Speed Map, Track and Weather.
- Today's Meetings table using canonical current meeting data and jurisdiction/PRA identity where appropriate.
- Today's Quick Stats only where counts are directly derivable from governed current-card data.
- Popular Tools / fast workspace navigation.
- Recent Results using governed completed-race results; SP only where price is shown.
- Top Performers / Last 5 Runs only where a governed ranking definition and historical form exist. Global finish-tile rule applies: 1 GOLD, 2 SILVER, 3 BRONZE, all other finish numbers WHITE with BLUE text.
- Insights only when evidence-backed by governed EDGEiQ feeds. No generated filler.
- Shared data freshness/source/footer treatment.

## Home data integrity
Every meeting, race, runner, statistic, result, SP, market movement, condition, weather value, ranking and insight visible in mockups is illustrative unless matched to canonical production data. Production must never copy mockup values. Unsupported widgets should truthfully show unavailable/empty state or be omitted.

## Home scope boundaries
Home is an orientation dashboard, not a second Overview, Insights, Market or Form screen. It should surface concise summaries and routes into specialist workspaces, not duplicate their full analysis.
